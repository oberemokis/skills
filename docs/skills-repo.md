# Один репозиторий на всех агентов: запись решения

Ноябрь 2026. До этого репозиторий был плагином Claude Code, а другие агенты получали копии скиллов, и копии расходились с оригиналом. Теперь клон этого репозитория единственный источник скиллов и ревьюеров для Claude Code, Codex, OpenCode и всех агентов, которые читают `~/.agents/skills`.

## Что знали, когда решали

- Claude Code находит скилл только как `~/.claude/skills/<имя>/SKILL.md`, первый уровень. `~/.agents/skills` он не читает. Ссылку на папку проходит.
- `~/.agents/skills` читают Codex, OpenCode, Kimi, Gemini CLI, Cursor, Copilot CLI, Amp, Goose, Devin, Droid.
- Codex ищет рекурсивно, проходит ссылки, незнакомые поля фронтматтера пропускает. Ручной вызов задаётся файлом `agents/openai.yaml` рядом со `SKILL.md`, вызов `$имя`. Агенты Codex лежат TOML-файлами в `~/.codex/agents`.
- OpenCode читает `~/.claude/skills`, `~/.agents/skills` и `~/.config/opencode/skills`, рекурсивно. `disable-model-invocation` понимает (версия 1.18.0 из Homebrew ещё нет), вызов `@имя`. Агенты Markdown со своими полями.
- `npx skills add` ставит копию: удаляет то, что лежит на месте, вместе со ссылкой. Скилл с `metadata.internal: true` он пропускает.
- Node 24: при запуске скрипта через ссылку `process.argv[1]` не равен пути модуля, и проверка «запущен ли я напрямую» на этом сравнении ложна: скрипт молча выходит с нулём. `import.meta.main` через ссылку работает.

## Что решили

- Репозиторий остаётся тем же, с историей. Плагин из него ушёл: манифест, changesets, версии, `package.json`, модуль хуков `fleet-panel`, калибровочные прогоны `evals`. Последняя версия плагина под тегом `v3.1.0`.
- Раскладка плоская: `skills/<имя>/SKILL.md`. Иначе Claude Code скилл не найдёт.
- Только скиллы и агенты. Глобальные инструкции агентов (`CLAUDE.md`, `AGENTS.md`) у каждого пользователя свои и сюда не входят.
- Установка у себя ссылками: `scripts/link.sh` ставит каждый скилл в `~/.claude/skills` и `~/.agents/skills`, ревьюеров в `~/.claude/agents` и `~/.config/opencode/agents`. Правка в клоне видна всем агентам сразу. Скрипт удаляет битые ссылки в клон, настоящую папку на месте ссылки не трогает и называет, предупреждает, если клон не на `main`. Повторный запуск ничего не меняет.
- Клон всегда на `main`, ветки в `.worktrees` клона: ссылки ведут в основную папку.
- Другим людям README предлагает `npx skills add` и предупреждает не запускать его поверх `link.sh`.
- `task-run` и `task-fleet` работают только в Claude Code внутри Herdr. У них `compatibility` с объяснением и `metadata.internal: true`: `link.sh` не ставит их в `~/.agents/skills`, `npx skills` пропускает. В OpenCode, который читает и `~/.claude/skills`, их закрывает политика в его настройках.
- Ручной вызов помечен парой: `disable-model-invocation: true` для Claude Code и OpenCode, `agents/openai.yaml` с `allow_implicit_invocation: false` для Codex. В описании такого скилла стоит «Вызывается вручную». Скилл `core` говорит о ручном вызове тремя формами: `/grill`, `@grill`, `$grill`.
- Ревьюер описан одним файлом `agents/<роль>.md`: во фронтматтере поля Claude Code (`tools`, `skills`) и OpenCode (`mode`, `permissions`), текст роли нейтральный. Поля `hidden` нет: в OpenCode 2.2.7 оно убирает агента из списка инструмента `subagent`, и на живой проверке модель вместо ревьюера запустила `general`. Claude Code и OpenCode получают ссылку на файл. Codex получает от `link.sh` TOML, в котором написано прочитать этот файл.
- В `core` таблица инструментов по действиям: с lean-ctx и без него. Агент без lean-ctx берёт свои инструменты.
- Скрипты скиллов проверяют запуск через `import.meta.main`, тест запускает каждый скрипт и напрямую, и через ссылку.
- Проверки одной командой `scripts/check.sh`: битые ссылки (в том числе пути в обратных кавычках), утечки по всему репозиторию (ID задач, внутренние хосты, личные пути, упоминания людей), `name` по стандарту и равный папке, пара пометок ручного вызова, `node --test`. Репозиторий публичный, поэтому главный барьер pre-push хук: `link.sh` включает его через `core.hooksPath`. Уже заданный `core.hooksPath` скрипт не перебивает, а просит вызвать хук клона из той папки: на репетиции локальное значение выключило бы глобальный `commit-msg`. CI запускает ту же команду.
- Скилл `lean-ctx` в репозиторий не входит: его ставит и обновляет сам lean-ctx.

## Что отвергли и почему

| Вариант | Причина отказа |
| --- | --- |
| плагин Claude Code и копии для остальных | копии расходятся, а правка доходит до агента только после переустановки |
| `npx skills` как способ установки у себя | ставит копию, правка в клоне не видна сразу |
| сгенерированные файлы агентов в git и генератор с `--check` | шесть копий двух текстов ради трёх форматов, а Codex хватает указателя на файл |
| копии `task-run` и `task-fleet` вместо ссылок | возвращают расхождение копий; после `lean-ctx uninstall` ссылки восстанавливает тот же `link.sh` |
| `--dry-run` и замена настоящих папок в `link.sh` | переезд разовый, а скрипт вечный; переезд расписан и отрепетирован отдельно |
| журнал установки и `link.sh --restore` | откат нужен один раз, хватает расписанного |
| флаг `OPENCODE_DISABLE_CLAUDE_CODE_SKILLS` | выключает и проектные `.claude/skills` |
| CI как защита от утечек | срабатывает уже после публикации |
| точный список запрещённых имён в проверке | сам опубликовал бы то, что прячет; проверка идёт по формам |

## Откат

1. Удалить ссылки, которые ставит `link.sh`: скиллы в `~/.claude/skills` и `~/.agents/skills`, ревьюеров в `~/.claude/agents` и `~/.config/opencode/agents`, TOML с пометкой `link.sh` в `~/.codex/agents`.
2. Вернуть папки из архива, сделанного перед переездом.
3. Убрать из настроек OpenCode политику, добавленную при переезде.
4. Клон остаётся как есть, ветка и коммиты не теряются.

## Как проверяем

| Случай | Где проверяется |
| --- | --- |
| битая ссылка, в том числе в обратных кавычках | `check.sh`, тест на фикстурах |
| утечка где угодно в репозитории, нет папки `skills` | `check.sh`, тест на фикстурах |
| одна пометка ручного вызова без другой | `check.sh`, тест на фикстурах |
| `name` не по стандарту или не равен папке | `check.sh`, тест на фикстурах |
| push с утечкой не проходит | pre-push хук |
| скрипт через ссылку работает как напрямую | `node --test`, `scripts/symlink-entry.test.mjs` |
| `task-run` и `task-fleet` есть в Claude Code и нет в `~/.agents/skills` | `link.sh` на временном `HOME` |
| повторный `link.sh` ничего не меняет, настоящая папка и клон не на `main` дают предупреждение | `link.sh` на временном `HOME` |
| правка в клоне видна всем агентам, ручной скилл не виден модели и вызывается вручную, ревьюер запускается, `core` работает без lean-ctx | живая проверка в Claude Code, OpenCode и Codex |
