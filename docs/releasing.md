# Версии и публикация

## Где живёт версия

В `package.json`. Оттуда она копируется в `.claude-plugin/plugin.json`, потому что плагин читает её из своего манифеста, а changesets умеет поднимать только в `package.json`.

Без этой синхронизации в манифесте навсегда остаётся версия, с которой репозиторий создавали.

## Порядок выпуска

```bash
pnpm changeset          # описать правку, выбрать patch, minor или major
pnpm version            # поднять версию, собрать CHANGELOG, обновить манифест
git add -A && git commit
git push
```

Дальше у себя: `/plugin marketplace update oberemokis`.

`pnpm changeset` создаёт файл в `.changeset/` с описанием изменения. Описание идёт в `CHANGELOG.md` как есть, поэтому писать надо для читателя: что изменилось в поведении и почему, а не какие файлы тронуты.

`pnpm version` делает четыре вещи по порядку:

1. `changeset version` поднимает версию в `package.json` и дописывает `CHANGELOG.md`, съедая файлы из `.changeset/`
2. `sync-plugin-version.mjs` копирует новую версию в манифест плагина
3. `sync-manifest.sh` пересобирает список скиллов
4. `gen-catalog.sh` пересобирает [каталог](./skills.md)

## Проверка

```bash
pnpm check
```

Ничего не меняет и падает, если версия в манифесте разошлась с `package.json`, если в манифесте есть путь без файла, если два скилла носят одно имя, или если каталог устарел. Годится для хука перед коммитом и для CI.

Отдельно ссылки:

```bash
./scripts/check-links.sh
```

## Что выбрать: patch, minor, major

Практика для репозитория с правилами, а не с кодом.

`patch` для правок формулировок, добавления примеров, исправления ошибок в существующих правилах.

`minor` для нового скилла, нового референса или нового правила, меняющего поведение агента.

`major` для перестройки структуры: переименование скилла, смена точки входа, изменение шаблона. То есть для всего, из-за чего у человека, читавшего предыдущую версию, устарело представление о репозитории.

## Первая установка не требует версии

`/plugin marketplace add oberemokis/skills` читает состояние ветки `main`, а не тег. Версия нужна для того, чтобы понимать, что поменялось между двумя моментами, а не для того, чтобы плагин установился.
