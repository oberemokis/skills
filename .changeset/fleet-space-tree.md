`task-fleet` метит каждую сессию задачи двумя метками: `task-fleet.space` с пространством оркестратора и `task-fleet.parent` с адресом его терминала. По ним сайдбар Herdr (мод `over9k` раскладки workbench из herdr-app) строит дерево: в пространстве оркестратора сверху сам оркестратор, под ним пространства задач, ниже прочие терминалы этого пространства, а пространства, заведённые руками, ниже всех деревьев. Связать их по git нельзя: оркестратор бывает в пространстве на `~`, а два оркестратора в одном репозитории по git неразличимы.

Восстановление в другом терминале перевешивает обе метки на себя, а сессиям, запущенным до 3.1.0, добавляет их.
