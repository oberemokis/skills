Общие скиллы (`test`, `test/bug-hunting`, `test/unit-tests`, `test/integration-tests`, `test/test-review`, `audit`, `git/commit`) больше не содержат блоков кода с командами и примерами. Агент копирует примеры, поэтому псевдокод без языка и раннера превращался в код без языка и раннера. Правила там описаны прозой с конкретным случаем. Примеры с компилятором и настоящим API остались в стековых скиллах. Блоки с шаблонами вывода (формат раунда, находки, полотно, сообщение коммита) сохранены. Правило про примеры уточнено в `docs/conventions.md`.
