# Этап show: дифф и показ

Одна остановка перед коммитом: пользователь видит дифф в gitone и результат в браузере вместе. После замечаний шаг повторяется целиком, поэтому в коммит уходит ровно тот дифф, который он одобрил.

## Стенд

Задача без интерфейса (только бэкенд, конфиг, CI): вместо браузера запрос к стенду или автотесты worktree, причина в итог. Раздел «Стенд» в `rules.md` говорит, что стенд проекта видит, а что нет.

Стенд из `project.json`, порт один на машину. Лок держит сам процесс сервера:

- запуск фоном из `<worktree>/<stand.cwd>`: `flock -n /tmp/task-run-port-<порт>.lock sh -c 'echo "<ID> <worktree>" > /tmp/task-run-port-<порт>.owner; exec <stand.start>'`;
- лок занят: прочитай `.owner`. Твоя задача: это твой прошлый сервер, перезапусти. Чужая: вопрос «Порт занят задачей <ID>», варианты «Подождать» и «Остановить». Чужой сервер не гаси;
- упал сервер, упал и лок: зависших локов не бывает.

## Сценарии

1. По одному на критерий приёмки, на L плюс граничные случаи и соседнее поведение. Скриншоты сохраняй вне worktree.
2. Сценарий не прошёл: чини, повтори затронутые автотесты и сценарий.

## gitone

Под herdr открой gitone в соседней панели своей вкладки, если его там нет (`herdr pane list --workspace "$HERDR_WORKSPACE_ID"`, заголовок терминала `gitone`): `herdr pane split --pane "$HERDR_PANE_ID" --direction right --cwd <worktree> --no-focus`, затем `herdr pane run <новая панель> "<команда>"`.

Команда по коммитам на ветке, `git rev-list --count origin/<база>..HEAD`:

- ноль: `gitone` без аргументов, он покажет всё незакоммиченное вместе с новыми файлами;
- больше нуля: `gitone $(git merge-base origin/<база> HEAD)`, а новые файлы (`git ls-files --others --exclude-standard`) перечисли в вопросе: с аргументами gitone их не показывает.

Без herdr напиши пользователю, какой командой открыть gitone в worktree.

## Вопрос

«Посмотри дифф в gitone и результат в браузере». В `preview`: сценарии с результатом, пути к скриншотам, diffstat, новые файлы.

- «Всё верно, доставлять» (рекомендую).
- «Есть замечания»: текстом через «Другое». Замечания в `findings` с `source: show`, затем implement, verify и этот шаг заново.
- «Остановить».

После одобрения запиши `reviewedDiff`: `git diff $(git merge-base origin/<база> HEAD) | shasum` вместе со списком новых файлов. Погаси свой сервер, чтобы отпустить порт.
