# Этап ask-product: вопрос продукту

1. Прочитай задачу и комментарии заново. Ответ уже есть: этап `skipped`, работай по нему.
2. Черновик по разделу «Вопрос продукту» в `rules.md`: по каждому пункту, что видит пользователь продукта сейчас, в чём развилка, два-три варианта простыми словами, рекомендация. Без полей, ключей, файлов и веток.
3. Вычитку попроси у пользователя: `/humanizer`. Сам этот скилл вызвать нельзя. Это ожидание, оформи его как вопрос.
4. Покажи текст целиком. Варианты: «Отправить», «Поправить», «Отвечу сам». Ответ пользователя считается решением продукта: в трекер ничего не уходит, ответ идёт в `decisions`.
5. Перед отправкой проверь по `state.md`, не отправлен ли уже такой вопрос. Отправка глаголом «задать вопрос продукту» только после подтверждения.
6. Отправлено: `stage.status = waiting-external`, `waiting` «ответ продукта», «приостановил». Сессия ждёт. Когда пользователь скажет, что ответ пришёл, прочитай его и продолжай с реализации.
