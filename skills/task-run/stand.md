# Стенд и вкладка

Задача с интерфейсом (в `context.pages` есть страницы) открывает браузер в начале implement, до первой правки, а не на шаге «Дифф и показ». Пользователь видит результат, пока его ещё дёшево поправить.

## Когда

- implement: первым шагом, до любой правки. Задача без страниц в `context.pages` стенд не поднимает.
- show и продолжение в новой сессии: стенд уже поднят, `port.mjs` его найдёт. Не поднят (сервер упал, машину перезагрузили): подними сейчас.
- Гаси стенд и закрывай вкладку после одобрения на show, а также при стопе, `blocked` и остановке по просьбе.

## Порт

У каждой задачи свой порт, параллельные задачи друг друга не ждут. Порты идут от `stand.port` из `project.json` и девять следующих: первая задача получает 3000, следующая 3001 и так далее.

1. `node <папка скилла>/scripts/port.mjs <stand.port> <ID>`. Ответ `{port, own}`: `own: true` значит, что стенд этой задачи уже стоит на этом порту, переходи к вкладке. Код 4: заняты все десять портов, вопрос «Порты стенда заняты», варианты «Подождать» и «Без стенда»; чужие серверы не гаси.
2. Запуск фоном из `<worktree>/<stand.cwd>`: `flock -n -E 75 /tmp/task-run-port-<порт>.lock node <папка скилла>/scripts/stand.mjs <порт> <ID> <worktree> "<stand.start>"`. Скрипт пишет владельца в `/tmp/task-run-port-<порт>.owner`, подставляет порт вместо `{port}` в `stand.start`, кладёт его в `PORT` и держит сервер. `sh -c` в своей команде не пиши: хук lean-ctx встроенный код не пропускает.
3. Код 75: порт успела занять другая задача между шагами 1 и 2, повтори с шага 1.
4. Сервер готов, когда порт отвечает. Упал сервер, упал и лок: зависших локов не бывает.

`stand.start` без `{port}` и без чтения `PORT` поднимет сервер на своём порту, а не на выданном: такой профиль поправь по `project.md`. Вход в приложение хранится отдельно для каждого порта, на новом порту пользователю может понадобиться войти снова.

## Вкладка

Вкладку открывает расширение Claude in Chrome (инструменты `mcp__claude-in-chrome__*`), чтобы пользователь видел и результат правок, и клики сценариев.

1. Своя новая вкладка на `http://localhost:<порт><страница>`, страница первая из `context.pages`. Чужие вкладки не трогай и не переиспользуй.
2. Dev-сервер сам обновляет страницу после правки. Перезагружай вручную, только если она не обновилась.
3. Сценарии show идут в этой же вкладке.
4. ID вкладки действует только в этой сессии. Продолжение в новой сессии открывает новую вкладку.

Расширения нет или оно не отвечает: открой адрес командой `open` и скажи об этом одной строкой. Сценарии тогда идут без него, пользователь видит их скриншоты в вопросе show.

## Скриншот с рамкой

Каждый скриншот, который видит пользователь, несёт красную рамку на том, что проверяется: правке или результате сценария. Скриншот без рамки не показывает, куда смотреть.

Страница открывается по адресу без входа и без кликов: снимок делает `scripts/shots.mjs` по разделу «Визуальное ревью» в `stages/review.md`, с `--out` в нужную папку. Иначе, во вкладке после шагов сценария:

1. Выбери селектор проверяемого элемента так же, как для `shots.mjs`: самый узкий элемент, который охватывает результат целиком.
2. Нарисуй рамку инструментом JavaScript расширения. Рамка отдельным слоем, разметку и стили страницы она не трогает; цвет и отступ как у `shots.mjs`:

   ```js
   (() => {
     document.getElementById('task-run-frames')?.remove()
     const layer = document.createElement('div')
     layer.id = 'task-run-frames'
     layer.style.cssText = 'position:absolute;left:0;top:0;width:0;height:0;z-index:2147483647;pointer-events:none'
     for (const el of document.querySelectorAll('<селектор>')) {
       const r = el.getBoundingClientRect()
       const frame = document.createElement('div')
       frame.style.cssText = `position:absolute;box-sizing:border-box;left:${r.left + scrollX - 7}px;top:${r.top + scrollY - 7}px;width:${r.width + 14}px;height:${r.height + 14}px;border:3px solid #ff2d2d`
       layer.append(frame)
     }
     document.documentElement.append(layer)
     return layer.childElementCount
   })()
   ```

   Ответ 0: селектор ничего не нашёл, поправь его. Без рамки не снимай.
3. Прокрути рамку в видимую область и сделай скриншот расширением. Файл скриншота расширение кладёт во временную папку `$TMPDIR/claude-chrome-screenshots-*/`: скопируй его в папку снимков с именем `<номер>-<что видно>` и прежним расширением, например `2-cart-empty.png`.
4. Убери рамку: `document.getElementById('task-run-frames')?.remove()`. Иначе она останется в следующих шагах сценария.

Без расширения скриншот с рамкой даёт только `shots.mjs`. Страницу за входом или после кликов он не снимет: назови её в итоге без скриншота.
