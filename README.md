# skills

Личные agent skills для Claude Code. Точка входа одна, дальше маршрутизация: любая задача проходит через [`skills/core`](./skills/core/SKILL.md), она передаёт в допрос и подтягивает нужные правила.

## Установка

```
/plugin marketplace add oberemokis/skills
/plugin install skills@oberemokis
```

Обновление после изменений:

```
/plugin marketplace update oberemokis
```

## Структура

```
skills/
├── core/          точка входа: grill, маршрутизация, завершение
├── grill/         дерево решений, фронтир, агенты
├── architecture/  слои монорепы, границы пакетов, куда положить код
├── test/          методологии тестирования: хаб и семь скиллов
├── stack/         правила и API по технологиям, одна папка на технологию
├── git/           работа с историей: commit
└── misc/          humanizer: правила текста для человека
```

Папка `design` заведена, но пуста, поэтому из манифеста исключена и в контекст не попадает. Пока в ней шаблон, а не правила, скилла `design` для агента не существует.

В `test` лежит хаб с общими правилами и семь скиллов под ним: `tdd`, `unit-tests`, `integration-tests`, `e2e-tests`, `test-review`, `coverage`, `bug-hunting`. Там методологии, а не инструменты: как писать тесты на конкретном раннере, смотри в `stack`.
